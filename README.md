Skills in this repo:

2. [product-discovery](https://github.com/michaelkerr/skillz/tree/main/product-discovery) — **Deprecated.** Use product-delivery instead.
3. [product-evolution](https://github.com/michaelkerr/skillz/tree/main/product-evolution) — **Deprecated.** Use product-delivery instead.
4. [product-delivery](https://github.com/michaelkerr/skillz/tree/main/product-delivery) — Unified lifecycle skill for software products — from first idea through delivery and stabilization. Replaces product-discovery and product-evolution with a single hierarchical state machine. Manages evidence-gated transitions, a nested work-item submachine, and a deterministic CLI for state management. Works across Claude Code, Cursor, ChatGPT/Codex, Hermes, and any agent with filesystem access.
5. [system-workspace](https://github.com/michaelkerr/skillz/tree/main/system-workspace) — Generate workspace-level context for a multi-repo system. Reads each repo's AGENTS.md and produces a thin workspace AGENTS.md capturing only cross-cutting concerns: shared conventions, cross-repo contracts, and workspace-wide constraints.
6. [zero-to-one-gtm](https://github.com/michaelkerr/skillz/tree/main/zero-to-one-gtm) — Founder-led go-to-market search from a rough product idea toward a repeatable first ten customers. One evidence folder per product, copied from the skill templates. Install into Cursor by copying this directory to `~/.cursor/skills/zero-to-one-gtm`.
